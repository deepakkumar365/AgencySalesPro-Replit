Instructions
  1. Download the Excel template using the button below
  2. Fill in the purchase order details following the template structure:
    • Order Group ID: Use the same ID for products belonging to one order (e.g., PO001). Leave blank for single-product orders.
    • Supplier Name: Must match an existing supplier name exactly (case-insensitive)
    • Order Date: Format YYYY-MM-DD (e.g., 2024-01-15)
    • Product Code: Product SKU code (must exist in the system)
    • Payment Type: Cash, Credit, or Credit Sale
  3. Mandatory fields: Supplier Name, Product Code, Quantity, Rate, Payment Type
  4. Upload the completed file using the form below
  5. Blank rows will be automatically skipped
