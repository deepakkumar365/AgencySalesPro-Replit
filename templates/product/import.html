Import Guidelines:
  • Supported formats: Excel (.xlsx, .xls) and CSV (.csv)
  • Required columns: Name, SKU, Price
  • Optional columns: Description, Cost, MRP, Category, UOM, Tax
  • Column Names: Case-insensitive (e.g., "category", "CATEGORY", "Category" all work)
  • Category Value: Must match an existing category name (case-insensitive matching)
  • UOM Value: Must match an existing Unit of Measure name (case-insensitive matching)
  • Tax Value: Must match an existing Tax Master name (case-insensitive matching)
  • If Category/UOM/Tax value doesn't match any master data, it will be left blank (import continues)
  • Duplicate SKUs will be skipped
