🚀 Getting Started

What is AgencySalesPro?

AgencySalesPro is a comprehensive multi-agency sales and business management system designed to help agencies manage:

🏢 Multiple Agencies

Support for separate agency accounts within one system

🛒 Sales & Orders

Complete order management lifecycle

👥 Customer Management

Track customers across agencies

💰 Financial Management

Payment, receipts, invoicing, and accounting

📋 Job Accounting

Project-based income and expense tracking

📦 Inventory

Stock management and purchase orders

Your Role as Super Admin

As a Super Admin, you have unrestricted access to the entire system. Your responsibilities include:

Key Responsibilities:
  • ✅ Creating and managing agencies
  • ✅ Managing users across all agencies
  • ✅ Viewing system-wide reports and analytics
  • ✅ Configuring system settings and defaults
  • ✅ Monitoring user activities and system health
  • ✅ Managing global products and pricing
  • ✅ Supporting agency administrators

Creating a New User

  1. Go to 👥 Users → Add New User
  2. Fill in required fields:
    • Username - Unique identifier (no spaces)
    • Email - Valid email address
    • Password - Strong password (min 8 characters)
    • Full Name - User's complete name
    • Role - Select from available roles
    • Agency - Assign to an agency
  3. Click Create User
💡 Pro Tip: For initial setup, set a temporary password and ask users to change it on first login.

Bulk User Import

For importing multiple users at once:

  1. Go to 👥 Users → Import Users
  2. Download the CSV template
  3. Fill in user information in the template
  4. Upload the CSV file
  5. Review the preview and click Import

🏢 Agency Management

Creating an Agency

Step 1: New Agency

  1. Navigate to 🏢 Agencies
  2. Click Create New Agency
  3. Fill in basic information:
    • Agency Name
    • Description
    • Contact Email
    • Phone Number
    • Address
    • Website (optional)

Step 2: Create Agency Admin

  1. Go to 👥 Users → Add New User
  2. Set Role to agency_admin
  3. Assign to the newly created agency
  4. This user will manage the agency

📦 Core Modules

Product Management

All products are managed globally, but each agency can override pricing and availability.

Creating a Product

  1. Go to 📦 Products → Add Product
  2. Fill in:
    • SKU - Unique code
    • Name - Product name
    • Description - Details
    • Category - Product category
    • Unit - Unit of measure
    • Base Price - Default price
  3. Click Create Product

💰 Finance & Accounting

Payments (Cash Out)

Record payments made to suppliers, vendors, and employees:

  1. Go to 💰 Finance → Payments
  2. Click New Payment
  3. Fill in payment details
  4. Optionally link to Purchase Orders
  5. Click Create Payment

Receipts (Cash In)

Record receipts from customers:

  1. Go to 💰 Finance → Receipts
  2. Click New Receipt
  3. Fill in receipt details
  4. Optionally link to Sales Orders
  5. Click Create Receipt

Job Accounting

Track project profitability with income and expense tracking.

Creating a Job

  1. Go to 📋 Job Accounting → Jobs → New Job
  2. Enter job details (name, type, customer, dates, budget)
  3. Click Create Job

Adding Income to Job

Income Categories: Deposit, Payment, Milestone, Bonus, Other

Adding Expenses to Job

Expense Categories: Materials, Labor, Overhead, Equipment, Travel, Marketing, Software, Subcontractor, Other

🔧 Troubleshooting & Support

Common Issues & Solutions

🔒 Login Issues

Problem: Cannot log in
Solutions:
  • Verify username/password is correct
  • Check if account is active (not deactivated)
  • Use "Forgot Password" link if needed
  • Check browser cookies are enabled

👤 User Management Issues

Problem: User cannot access certain features
Solutions:
  • Check user role - ensure proper permissions
  • Verify user's agency assignment
  • Check if user is active (not deactivated)
  • Try refreshing page or re-logging in

📦 Product Issues

Problem: Cannot find product
Solutions:
  • Check product name/SKU in search
  • Verify product is not deactivated
  • Check if product is mapped to user's agency

💰 Finance Issues

Problem: Cannot see Finance menu
Solutions:
  • Check user role has finance access
  • Super admins always have access
  • Agency admins and staff should have access

Best Practices

✅ DO

  • Use strong passwords
  • Review Activity Log regularly
  • Keep user info up-to-date
  • Make regular backups
  • Document configurations
  • Deactivate unused accounts

❌ DON'T

  • Share passwords
  • Use weak/generic passwords
  • Leave admin accounts inactive
  • Delete historical data carelessly
  • Create test data in production
  • Ignore security warnings
