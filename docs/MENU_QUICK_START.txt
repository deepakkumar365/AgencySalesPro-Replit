──────────────────────────────────────────────────────────────────────────────
TROUBLESHOOTING
──────────────────────────────────────────────────────────────────────────────

Problem: "AttributeError: no attribute 'role_id'"
Solution: Ensure user has role_id set in session during login
         Add: session['role_id'] = user.role_id

Problem: "No such table: ASP_menu_items" or "ASP_menu_roles"
Solution: Run seed script: python seed_menus.py

Problem: Menus not showing up
Solution: Check:
  1. Is user logged in? (session.user_id exists)
  2. Does user have role_id? (session.role_id exists)
  3. Are menus assigned to role? (check in admin panel)
  4. Clear browser cache/cookies

Problem: Cache not working
Solution: Check Redis connection:
  - Windows: Use WSL2 or Docker
  - Linux/Mac: redis-cli ping
  System will fallback to simple cache automatically

Problem: CSRF token errors in menu management
Solution: Ensure form includes csrf token (usually in base template)

──────────────────────────────────────────────────────────────────────────────
API EXAMPLES (for developers)
──────────────────────────────────────────────────────────────────────────────

Get menus for a role:
  curl http://localhost:5000/super_admin/api/role/1/menus

Get roles for a menu:
  curl http://localhost:5000/super_admin/api/menu/1/roles

Add role to menu:
  curl -X POST http://localhost:5000/super_admin/api/menu/1/roles \
    -H "Content-Type: application/json" \
    -d '{"role_id": 2}'

Remove role from menu:
  curl -X DELETE http://localhost:5000/super_admin/api/menu/1/roles \
    -H "Content-Type: application/json" \
    -d '{"role_id": 2}'

INTEGRATION WITH TEMPLATES

      </a>
      {% if menu.children %}
        <ul>
          {% for child in menu.children %}
            <li>
              <a href="{{ url_for(child.url) }}">
                <i class="{{ child.icon }}"></i> {{ child.name }}
              </a>
            </li>
          {% endfor %}
        </ul>
      {% endif %}
    </li>
  {% endfor %}
