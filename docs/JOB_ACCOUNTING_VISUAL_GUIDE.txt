┌──────────────────────────────────────────────────────────────────────────────┐
│                        INCOME CATEGORIES                                     │
└──────────────────────────────────────────────────────────────────────────────┘

    💵 DEPOSIT          → Advance payment from client
    💰 PAYMENT          → Regular payment received
    🎯 MILESTONE        → Payment on reaching milestone
    🎁 BONUS            → Extra payment/bonus
    ↩️  REFUND          → Money returned
    📦 OTHER            → Any other income


┌──────────────────────────────────────────────────────────────────────────────┐
│                        EXPENSE CATEGORIES                                    │
└──────────────────────────────────────────────────────────────────────────────┘

    📦 MATERIALS        → Physical/digital goods purchased
    👷 LABOR            → Employee salaries, contractor fees
    🏢 OVERHEAD         → Rent, utilities, general costs
    💻 EQUIPMENT        → Tools, hardware, software licenses
    ✈️  TRAVEL          → Transportation, accommodation
    📢 MARKETING        → Advertising, promotion costs
    🤝 SUBCONTRACTOR    → Outsourced work
    📄 OTHER            → Any other expense


┌──────────────────────────────────────────────────────────────────────────────┐
│                        TRANSACTION STATUS                                    │
└──────────────────────────────────────────────────────────────────────────────┘

    ⏳ PENDING          → Expected but not yet confirmed
                         (NOT counted in totals)

    ✅ CONFIRMED        → Verified and received/paid
                         (COUNTED in totals)

    ❌ CANCELLED        → Transaction cancelled
                         (NOT counted in totals)

┌──────────────────────────────────────────────────────────────────────────────┐
│                        PROFIT CALCULATION                                    │
└──────────────────────────────────────────────────────────────────────────────┘

    Step 1: Sum all CONFIRMED income
    ┌─────────────────────────────────────┐
    │ Income #1: ₹50,000 (Confirmed) ✅   │
    │ Income #2: ₹50,000 (Confirmed) ✅   │
    │ Income #3: ₹50,000 (Confirmed) ✅   │
    │ Income #4: ₹20,000 (Pending)   ⏳   │ ← Not counted
    │ Income #5: ₹10,000 (Cancelled) ❌   │ ← Not counted
    └─────────────────────────────────────┘
    Total Income = ₹150,000

    Step 2: Sum all CONFIRMED expenses
    ┌─────────────────────────────────────┐
    │ Expense #1: ₹40,000 (Confirmed) ✅  │
    │ Expense #2: ₹40,000 (Confirmed) ✅  │
    │ Expense #3: ₹20,000 (Confirmed) ✅  │
    │ Expense #4: ₹15,000 (Pending)   ⏳  │ ← Not counted
    └─────────────────────────────────────┘
    Total Expenses = ₹100,000

    Step 3: Calculate profit
    ┌─────────────────────────────────────┐
    │ Net Profit = Income - Expenses      │
    │ Net Profit = ₹150,000 - ₹100,000    │
    │ Net Profit = ₹50,000 ✅              │
    └─────────────────────────────────────┘

    Step 4: Calculate profit margin
    ┌─────────────────────────────────────┐
    │ Profit Margin = (Profit/Income)×100 │
    │ Profit Margin = (50,000/150,000)×100│
    │ Profit Margin = 33.33% ✅            │
    └─────────────────────────────────────┘
