================================================================================
                         KEY DATA FLOW IMPLEMENTED
================================================================================

1. REGISTER VEHICLE
   └─ Customer arrives → Vehicle registered in system → Linked to customer

2. CREATE WORK ORDER
   ├─ Service Advisor selects customer & vehicle
   ├─ Adds services from catalog
   ├─ Adds parts from inventory
   ├─ Assigns technician
   └─ Status: ESTIMATE

3. APPROVE
   └─ Service Manager reviews & approves → Status: APPROVED

4. START WORK
   └─ Technician starts job → Status: IN PROGRESS

5. COMPLETE WORK
   ├─ Technician finishes services
   ├─ Parts consumed recorded
   ├─ Status: COMPLETED
   └─ ✓ INVENTORY AUTO-DEDUCTED

6. DELIVER
   └─ Service Advisor marks delivered → Status: DELIVERED
